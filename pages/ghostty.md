# [Ghostty](https://ghostty.org) (`ghostty`)

A fast, feature-rich, and cross-platform terminal emulator that uses platform-native UI and GPU acceleration.

## Configuration

Ghostty's design follows the [Zero Design Philosophy](https://ghostty.org/docs/config#zero-configuration-philosophy). So Ringo aims to have least configuration possible. Yet, Ghostty's uncustomizable tabs constantly remind me of [kitty](https://sw.kovidgoyal.net/kitty).

:::note
The `kitty` package is also included in Ringo as a fallback for Ghostty.
:::
