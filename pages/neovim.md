# [NeoVim](https://neovim.io) (`neovim`)

Hyperextensible Vim-based text editor.

## Configuration

Ringo ships a fully-featured configuration including a Fancy UI, File Browser, Fuzzy Finder, Tree-sitter, LSP, and language-specific plugins,
which is heavily inspired by [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim).
