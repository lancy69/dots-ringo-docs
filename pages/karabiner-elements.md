# [Karabiner-Elements](https://karabiner-elements.pqrs.org) (`karabiner-elements`)

A powerful and stable keyboard customizer for macOS.

## Additional Setup

The installation of Ringo only adds custom keyboard mappings to Karabiner, but does not enable them.
To try out these mappings, enable them under **Karabiner-Elements Settings > Complex Modifications > Add predefined rule > Lancy's Mappings**.

## Configuration

Ringo have defined some simple QoL mappings with Karabiner-Elements, mostly remapping useless keys on board.
